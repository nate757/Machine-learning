# Lab 4: Ticket Escalation Classification

Notebook: `Lab4_ticket_escalation.ipynb` (ML and Big Data). Dataset: `classification_escalation.csv`.

Compares a majority baseline, logistic regression, LDA and k-NN with precision/recall/F1/ROC-AUC, a threshold and cost analysis (5 x FN + FP), cross-validated k-NN tuning, and a written recommendation.
